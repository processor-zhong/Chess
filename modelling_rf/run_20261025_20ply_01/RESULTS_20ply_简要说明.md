# 前十个完整回合 随机森林实验结果

预测时点改为**双方各走10步，共20个半回合结束后**。旧10半回合版及其结果保留。
本次仍只使用随机森林，比较同一算法、相同参数下的赛前6列与赛前加开局46列。

## 数据和实现

- 继承原始清洗结果和固定时间分区，24小时边界间隔保持不变。
- 排除原间隔410场，以及活跃分区中在第20个半回合及之前结束的1,651场。
- 前20个半回合全部合法且未终局的合格对局17,050场，解析失败0场。
- 训练11,936场，验证2,549场，测试2,565场。
- 特征只用前20个半回合，计数类字段改为first20，局面审计字段为position_fen_at_ply20。
- 数据结构/解析/接口检查通过88项；最终结果另通过25项预测和指标一致性检查。

## 测试结果

| 指标 | 仅赛前 | 赛前＋20半回合开局 |
|---|---:|---:|
| Accuracy | 55.95% | 61.64% |
| Macro-F1 | 0.4177 | 0.4495 |
| Balanced Accuracy | 41.92% | 45.02% |
| 和棋 Recall | 8.33% | 5.30% |
| Log Loss，越低越好 | 0.9101 | 0.8836 |

在同一批测试对局上，加入20半回合信息使Accuracy提高5.692个百分点、Macro-F1提高0.03184，Log Loss降低0.02650。
但是和棋Recall下降；开局版只识别出132场和棋中的7场，Precision为12.73%。
因此不能仅依据整体准确率评价三分类能力，和棋识别仍是主要弱项。

## 调参与冻结

同一12组参数网格、每组两个信息集各3折训练内时间CV。按两组CV Macro-F1平均值取前3组，再按验证集两组Macro-F1平均值选共享参数。
最终冻结200棵树、最大深度16、叶节点至少10个样本、max_features=sqrt、class_weight=balanced、random_state=42。
预测为概率argmax，没有用测试集调阈值。

验证集赛前版Macro-F1=0.4251，开局版=0.4467，因此本轮在测试前偏好的版本就是combined。
两版模型按预先固定政策在训练+验证14,485场上重训完整Pipeline，再统一评价测试集。

## 与旧预测时点的关系

不能直接把旧10半回合版的整体指标与新版整体指标相减，因为对局筛选、训练样本和选定参数都变了。
`tables/checkpoint_common_cohort_metrics.csv`使用两版已经保存的预测，固定为同一批2,565场测试对局；没有重新给模型打分或调参。
这个表只控制了测试样本，不控制训练队列与参数，故仍属于版本表现描述，不能隔离“只多看5个回合”的净效果。

更重要的是，本次变更发生在上一轮测试表现已经被查看之后，并沿用相同历史测试时间段。
虽然本轮参数在再次评分前冻结，结果仍属于**后续探索性实验**，不能称为全新未接触的确认性测试，也不应继续依据测试成绩搜索更多时点。
本次没有计算显著性，不声称稳定或因果提升。
