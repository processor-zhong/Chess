# 数据协议与特征

来源为Kaggle datasnaek/chess的固定快照；data/raw/games.csv保持原始字节，SHA-256记录在data/raw/provenance.json中。

## 清洗及划分

20,058条原始记录按对局ID去重（945条多余记录），再排除2场双方账号相同的记录，得到19,111个独立ID。
重复ID若只有时间字段分辨率不同，保留有效数字更多的时间戳记录，以原始行号打破平局。此规则是精度代理，不保证时间戳绝对准确。
开始/结束时间相同的记录没有简单当作“无效比赛”删除；原快照存在时间戳精度混合问题。
原时间分区按完整UTC日，目标约70/15/15，边界前留24小时间隔，并检查较早结果已记录；manifest在本版中不重新分配。
410场边界间隔记录保留在审计中，不参与训练/评估。

## 本版筛选

只纳入棋谱超过20个SAN token、前20个全部合法且截止局面未终局的比赛。
原活跃分区中1,651场在该时点或之前结束，排除。17,050场合格对局前缀解析成功。
Train=11,936；Validation=2,549；Test=2,565。
模型结论只适用于持续到该时点的对局，不能推广到更早结束的比赛。

## 输入

赛前6列：rating_diff、avg_rating、abs_rating_diff、base_time_min、increment_seconds、rated。
开局40列：棋子数量、子力、发展代理、中心占据/攻击、攻击范围、兵推进、易位历史/权利、王位置、前20半回合吃子及将军次数等。
详细定义以tables/plan_a20/feature_dictionary.csv为准。attack不是合法着法数；minor_off_home_rank是发展代理，不追踪棋子原始个体。
所有特征是未缩放数值，Pipeline在各训练折内拟合插补和常量列移除。随机森林不需要标准化。

meta保存ID、时间、棋手ID和截止FEN，供追溯，不能输入模型。完整棋谱及opening_name/opening_ply等赛后描述不作为输入。

## 局限

便利抽样来自选定Lichess用户，不代表全部棋手或当前平台。棋手可能跨分区出现，时间区间的等级分和时间规则分布也不同。
时间戳精度差异、少数和棋和观察时点的样本筛选影响外推。
测试区间已经在早期时点实验被查看，本版属于后续探索，不是全新确认性盲测。
